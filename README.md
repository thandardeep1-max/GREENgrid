# 🌱 GreenGrid

**GreenGrid** is an AI-powered smart agriculture platform that helps farmers make better farming decisions using AI, IoT, weather data, and market analysis.

## 🚀 Features

- 🌱 AI Soil Detection
- 🦠 Plant Disease Detection
- 🔬 IoT-Based Soil Testing
- 🌾 Crop Recommendation
- 📅 Crop Calendar
- 🌦️ Weather Alerts
- 💰 Crop Selling Profit Comparison
- 🗣️ Voice & Language Support
- 📱 Offline/Low-Connectivity Support

## 🛠️ Technology Stack

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- MySQL
- TensorFlow / Keras
- Arduino

## 🎯 Objective

To provide farmers with a simple platform for soil analysis, disease detection, crop recommendations, weather monitoring, farming guidance, and profit optimization.

## 👥 Project

Developed as an **AI & Smart Agriculture Hackathon Project**.
